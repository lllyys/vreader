### WI-6a note (test-authoring bug caught + fixed at Gate-5)

The initial Gate-5 pass (v0.16.0) found `BookDetailsSheetTest.rendersAcrossThemes` and `MorePopupTest.rendersAcrossThemes` RED — a **test-code bug** (both looped `compose.setContent{}` inside `for (theme in ReaderTheme.values())`; `AndroidComposeTestRule.setContent` may be called only once per test → `IllegalStateException`). **No product defect** — every acceptance-relevant test in both suites already passed and the product verified end-to-end on real books. Fixed on branch `fix/134-theme-test-setcontent` (single `setContent` per test: sheet = a `Column` asserting count == theme count; popup = state-driven single tree), Gate-4 ship-as-is (Codex thread `019f515b…`), shipped as android/v0.16.1 (PR #1949). Both suites re-run green (14/0, 11/0) on v0.16.1.
