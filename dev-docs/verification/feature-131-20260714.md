- EPUB: `test-books/books/epub/道诡异仙 - 狐尾的笔.epub` — 18 MB CJK EPUB, present in the main checkout (EPUB DOM-injection acceptance path over the real Readium DOM).

- Synthetic (documented real-books-first exceptions — androidTest cannot read gitignored `test-books/`, and the interlinear render needs a deterministic seeded translation cache to assert exact spans): the connected classes seed the Room `chapter_translations` cache directly (the exact bytes a real AI translation would cache), so the app-side fetch→cache→render pipeline is exercised with ZERO live provider — which is precisely the cache-render acceptance criterion. `EpubBilingualConnectedTest` runs over a bundled minimal EPUB through the real Readium navigator; `BookOpenerTest` opens a bundled minimal EPUB.
- **AI boundary**: the real-provider translation leg (network → AiClient → chunk → cache) is covered by (a) the #118 AiClient provider stack, already Gate-5-verified against real providers, and (b) the WI-3/WI-4a JVM service tests over a fake AiClient. NOTE: the repo's ad-hoc OpenRouter smoke (`.secrets/test-llm.sh`) is currently inconclusive only because its pinned free model `openrouter/owl-alpha` was retired upstream (404 "No endpoints found") — a model-deprecation, not a wire-format regression; the app never uses that script (it drives its own #118 provider profiles).
