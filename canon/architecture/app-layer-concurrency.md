# Architecture — app layer and concurrency model

## Purpose

The app layer (`vreader/App/`) boots the iOS app: it resolves configuration, builds the SwiftData container, constructs the long-lived service graph (persistence, importer, downloads, translation, debug bridge), and injects live references into SwiftUI via Environment keys defined in `vreader/Utils/`. It also encodes the project's Swift 6 strict-concurrency conventions — which types are `actor`s, which are `@MainActor`, and where the app layer's three `MainActor.assumeIsolated` call sites live.

## Key files and types

- `vreader/App/VReaderApp.swift` — `@main @MainActor struct VReaderApp: App`. `init()` constructs the core service graph synchronously, but dispatches several bootstrap operations asynchronously rather than blocking on them: `ChapterTranslationStore` and `BookTranslationCoordinator` configuration each run in an unstructured `Task`, and `WebDAVProfileMigrator.migrateIfNeeded()` runs in a `Task.detached`; `body` is a single `WindowGroup`. Also hosts the DEBUG-only `struct TestLaunchConfig: Sendable` (`static func parse(_ arguments: [String]) -> TestLaunchConfig`, 31 launch flags such as `--uitesting`, `--seed-books`, `--enable-ai`, `--mock-ai`, `--tts-test-mode`, `--reader-default-layout=`) and `TestLaunchModifier: ViewModifier`.
- `vreader/App/VReaderAppDelegate.swift` — `final class VReaderAppDelegate: NSObject, UIApplicationDelegate`, bridged via `@UIApplicationDelegateAdaptor`. Captures `application(_:handleEventsForBackgroundURLSession:completionHandler:)` into a `@MainActor static var backgroundCompletionHandlers: [String: () -> Void]` (with `storeBackgroundHandler` / `takeBackgroundHandler`) for the lazy-download background URLSession (feature #47 WI-3b). If a duplicate handler arrives for the same identifier, the previous one is invoked before replacement so iOS's background-launch grace period is not leaked.
- `vreader/App/AppConfiguration.swift` — `struct AppConfiguration: Sendable` + `enum AppEnvironment: String, Sendable, CaseIterable` (`dev`/`staging`/`prod`). Reads Info.plist key `VReaderEnvironment` case-insensitively; missing/unrecognized values fail safe to `.prod`; `#if !DEBUG` force-overrides any non-prod value to `.prod`. Provides `apiBaseURL` (dev `http://localhost:8080/api`, staging `https://staging-api.vreader.app/api`, prod `https://api.vreader.app/api`), `retryCount` (1/2/3), `timeoutSeconds` (10/20/30).
- `vreader/App/ModelContainerFactory.swift` — `enum ModelContainerFactory` with `makeContainer(schema:configuration:) throws -> ModelContainer` and `shouldApplyMigrationPlan(storeURL:fileManager:)`. Applies `VReaderMigrationPlan` only when the store file already exists on disk; fresh installs and in-memory stores skip it (bug #186 / GH #633 — the plan materialized SchemaV1–V5 on the main thread and caused a multi-second first-launch freeze).
- `vreader/App/AITestSetup.swift` (DEBUG) — `@MainActor enum AITestSetup`; `apply(...)` sets all three AI gates (`AITestOverride.forceAvailable`, `featureFlags.aiAssistant`, `consentManager.grantConsent()`) so `--enable-ai` / `--mock-ai` exercise the full request path (bug #237 follow-up). `nanosForDelayMS` clamps to a 60s ceiling.
- `vreader/App/TestSeeder.swift` (DEBUG, 987 lines) — `enum TestSeeder`, fixture seeding via `PersistenceActor.insertBook()` for UI tests.
- `vreader/Utils/` Environment keys: `PersistenceActorEnvironment.swift` (`\.persistenceActor: PersistenceActor?`), `BookImporterEnvironment.swift` (`\.bookImporter: (any BookImporting)?`), `LazyDownloadCoordinatorEnvironment.swift` (`\.lazyDownloadCoordinator: LazyDownloadCoordinator?`), `WebDAVNetworkPolicyEnvironment.swift` (`\.webDAVNetworkPolicy: WebDAVNetworkPolicy?`). All default to nil (previews/tests treat them as optional).
- Other `vreader/Utils/` members: `AppLogger.swift` (OSLog `Logger`s, subsystem `com.vreader.app`), `ContentHasher.swift` (streaming SHA-256 via CryptoKit; cancellation rethrown as `ImportError.cancelled`), `EncodingDetector.swift` (TXT pipeline: BOM sniff → binary masquerade → strict UTF-8 → NSString heuristic → CP1252 → lossy UTF-8), `ErrorMessageAuditor.swift` (error → user message, no path leakage), `FileSizeFormatter.swift`, `HighlightedSnippet.swift`, `MonthBoundary.swift` (feature #67), `QuoteRecovery.swift` (quote-based position fallback), `ReadingTimeFormatter.swift`, `AccessibilityFormatters.swift`, `ReduceMotionHelper.swift`.
- `project.yml` — xcodegen manifest: `SWIFT_VERSION: "6.0"`, `SWIFT_STRICT_CONCURRENCY: complete`, iOS deployment target 17.0, `PRODUCT_BUNDLE_IDENTIFIER: com.vreader.app`, `MARKETING_VERSION: 3.67.6` / `CURRENT_PROJECT_VERSION: 1048` (as read; bumped every PR per the version-bump rule). One SPM package: Readium swift-toolkit `exactVersion: "3.9.0"` (ReadiumShared + ReadiumStreamer + ReadiumNavigator only). Vendored libmobi C compiles into the app target with `-w` scoped to `vreader/Services/Libmobi/src`, exposed via `SWIFT_OBJC_BRIDGING_HEADER: vreader/SupportingFiles/Libmobi-Bridging-Header.h`, `USE_LIBXML2=1`, `-lxml2`. `NSAllowsArbitraryLoads: true` (bug #110 — user-entered HTTP WebDAV hosts). `UIAppFonts` bundles Source Serif 4 + Inter (feature #60 WI-1b). `CFBundleDocumentTypes` registers EPUB/PDF/TXT/MD/Kindle with `LSHandlerRank: Alternate` plus imported UTIs `com.amazon.azw3` / `com.amazon.mobi-pocket` (feature #59 WI-1).
- `TestPlans/All.xctestplan` (default plan: vreaderTests + vreaderUITests) and `TestPlans/Verification.xctestplan` (feature #45 WI-6 — a checked-in selected-tests list of per-method verification XCUITests, e.g. `Feature23TXTTocVerificationTests/test_verify_feature_23_txt_toc_navigation_jumps_to_chapter()`).
- `vreader/Services/BackgroundExecutionToken.swift` — `@MainActor final class BackgroundExecutionToken` wrapping UIKit's `beginBackgroundTask`/`endBackgroundTask` (feature #98): a single-use handle so in-flight translation work (`BookTranslationCoordinator`) survives iOS's ~30s background grace window. Explicit `end()` is the contract — `deinit` only logs a leak in DEBUG (calling back from a nonisolated deinit is a Swift 6 isolation hazard); the expiration handler strongly captures the end-state so a dropped token still self-ends at expiry. `BackgroundExpiryLatch` (lock-backed, `Sendable`) lets a job loop detect expiry between work units without an actor-hop race.
- `vreader/Services/KeychainService.swift` — `struct KeychainService: Sendable` wrapping `kSecClassGenericPassword` Keychain CRUD (`kSecAttrAccessibleWhenUnlockedThisDeviceOnly` — unlocked-device-only, excluded from backups) for secrets and the persistent `deviceId()`. `deviceId()` uses an atomic add-or-read (SecItemAdd first, read the winner on `errSecDuplicateItem`) to avoid a check-then-act race on first access; `resetDeviceId()` backs the Settings "Reset Sync Identity" action. Coordinates with `AppConfiguration.swift`.

## Bootstrap sequence (`VReaderApp.init()`)

1. `AppConfiguration()` → `FeatureFlags.shared.configure(environment:)`.
2. DEBUG: `TestLaunchConfig.parse(ProcessInfo.processInfo.arguments)`; `--seed-corrupt-db` short-circuits into the error-screen state.
3. `Schema(SchemaV10.models)`; UI-test launches get an in-memory `ModelConfiguration` unless a seed needs disk persistence (whitelist incl. `seedPositionTest`, `seedKeepExisting` — bug #151 / GH #423: in-memory dies on `app.terminate()`).
4. `ModelContainerFactory.makeContainer(schema:configuration:)` (migration plan only for existing stores).
5. `LocatorKeyBackfillMigration.run(container:defaults:)` — feature #109 one-shot NFC locator-key backfill (bug #356), UserDefaults-gated, skipped for in-memory stores.
6. `Task { await ChapterTranslationStore.shared.configure(modelContainer:) }` (feature #56 WI-2) and a second Task wiring `BookTranslationCoordinator.shared.configure(service:backgroundTasks:resolver:)` with an `AIService` and `promptVersion: "bilingual-v1"` (feature #56 WI-14, feature #98).
7. `ReadingModeMigration.run(defaults:perBookBaseURL:)` — synchronous, before any `ReaderSettingsStore` exists (feature #54 WI-5).
8. DEBUG: `AITestSetup.apply(...)` (outside the `isUITesting` gate so `simctl openurl` DebugBridge runs get it too), kindle-convert flag overrides (feature #42 / bug #325), then seeding via `Task.detached` + `DispatchSemaphore` with a 5.0s bounded wait.
9. Production graph: `PersistenceActor(modelContainer:)` → `BookImporter(persistence:sandboxBooksDirectory:)` (Application Support/`ImportedBooks`) → `ContentView(viewModel: LibraryViewModel(persistence:importer:preferenceStore: UserDefaultsPreferenceStore()), syncMonitor:)` cached as a stored property so `body` never rebuilds the ViewModel → `FileURLImportRouter(bookImporter:)` (feature #59 WI-2).
10. `WebDAVNetworkPolicy()` and `LazyDownloadCoordinator(session:persistence:finalizer:)` built inside `MainActor.assumeIsolated` blocks; the background `URLSessionBackgroundSession` identifier is `"com.vreader.app.book-downloads"`; `LazyDownloadFinalizer` wiring is bug #115's fix (without it downloaded books stayed `.remoteOnly`).
11. DEBUG: `DebugBridge(context: RealDebugBridgeContext(persistence:importer:))` built synchronously so `.onOpenURL` never races a nil bridge.
12. `Task.detached(priority: .background)` → `WebDAVProfileMigrator.migrateIfNeeded()` (feature #52 WI-2; idempotent via marker key `com.vreader.webdav.profilesMigrated.v1`).

`body` injects `.modelContainer(modelContainer)` plus the four Environment values and wires `.onOpenURL`: in DEBUG, `url.scheme == DebugCommand.scheme` (`"vreader-debug"`, `DebugCommand.swift:480`) dispatches to `debugBridge.handle(url)`; everything else falls through to `fileURLRouter?.dispatch(url)`. Release handles only file URLs (the debug scheme is never registered — the `CFBundleURLTypes` injection in `project.yml` is Debug-only). On container failure, a fallback "Unable to Open Library" view shows `sanitizedErrorMessage(_:)` (special-cases `NSCocoaErrorDomain` code 134110; never exposes paths).

## Concurrency model

- **Strict concurrency**: `SWIFT_STRICT_CONCURRENCY: complete` under Swift 6.0 (`project.yml`).
- **Actors own mutable service state**: `actor PersistenceActor: BookPersisting` (`vreader/Services/PersistenceActor.swift:125` — all SwiftData mutations; returns record value types, never `@Model` instances), `actor ChapterTranslationStore` (`vreader/Services/ChapterTranslationStore.swift:29`), `actor BookTranslationCoordinator` (`vreader/Services/AI/BookTranslationCoordinator.swift:45`). See [[Module — persistence and data model]] and [[Module — bilingual translation]].
- **UI types are `@MainActor`**: `@Observable @MainActor final class LibraryViewModel`, `@Observable @MainActor final class ReaderSettingsStore`, `@MainActor final class FileURLImportRouter`, `@MainActor final class DebugBridge`.
- **`@MainActor` is not serialization**: `DebugBridge.handle(_:)` chains each command Task on the previous one (`pendingTask`) for FIFO semantics, because actor methods are reentrant across `await` and `.onOpenURL` spawns independent unstructured tasks (comment at `DebugBridge.swift:182-185`). See [[Module — debug bridge]].
- **Lock-based Sendable singleton**: `nonisolated final class FeatureFlags: Sendable` (`vreader/Services/FeatureFlags.swift:67`) guards state with `OSAllocatedUnfairLock<Storage>`; persisted flags (`aiAssistant`, `epubContinuousScroll`, `readiumEPUBEngine`, `kindleConvertOnImport`, `agenticTools`) round-trip UserDefaults under prefix `com.vreader.featureFlags.`.
- **`MainActor.assumeIsolated` has three app-layer call sites across two conceptual contexts**: two inside `VReaderApp.init()` (`WebDAVNetworkPolicy()` and `LazyDownloadCoordinator(...)` construction — legal, the App struct is `@MainActor`), plus one in `VReaderAppDelegate`'s `handleEventsForBackgroundURLSession` UIKit callback (UIKit guarantees main thread; the handler must be stored synchronously or it races `urlSessionDidFinishEvents`). Elsewhere in the codebase the reader bridges and TTS use the same pattern on main-queue UIKit/notification callbacks.
- **DI is constructor injection + SwiftUI Environment**: protocols at boundaries (`BookImporting`, `LibraryPersisting`); the four Environment keys carry live references to sub-screens (e.g. `WebDAVSettingsView`) without threading through every parent.

## Edge cases and invariants

- Every field of `VReaderApp` is set on every init path (success, corrupt-DB seed, catch), so the struct is total even when the container fails.
- Seeding blocks init at most 5 seconds (`semaphore.wait(timeout: .now() + 5.0)` → `assertionFailure` on timeout).
- `--reset-preferences` (bug #152 / GH #426) wipes `TestSeeder.knownPreferenceKeys` synchronously before any ViewModel reads UserDefaults; it is opt-in.
- The backfill migration is skipped for in-memory stores so an ephemeral UI-test launch cannot set the one-shot gate flag and starve the real on-disk backfill.
- Release builds force `.prod` environment via override, not `assert()` (which is stripped when optimized).
