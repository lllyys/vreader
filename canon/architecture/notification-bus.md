# Architecture — notification bus

## Purpose

Cross-component reader/library/settings communication runs over `NotificationCenter`, because SwiftUI `Environment` does not bridge into the UIKit/WKWebView coordinator layer where reader bridges live. The bus decouples format-specific bridges (TXT/MD/EPUB/PDF/Foliate) from the shared chrome host `ReaderContainerView`, and gives services (importer, persistence, download coordinator, profile stores) a view-agnostic change signal.

## Key files and counts

- `vreader/Views/Reader/ReaderNotifications.swift` — the canonical production catalog: **58** `Notification.Name` declarations plus the payload types `TextSelectionInfo` (`selectedText` / `startUTF16` / `endUTF16`, `Sendable`), `ReaderSelectionEvent` (`selectedText` / `anchor: AnnotationAnchor` / `sourceRect: CGRect`), `PDFHighlightNotificationPayload`, `ReaderHighlightTapEvent` (`highlightID: UUID`, `sourceRect: CGRect`, `openInEditMode: Bool = false`), `ReaderHighlightEditRequest` (GH #1121), and the helper `@MainActor func resolveHighlightColor(from:) -> String` (falls back to `"yellow"`).
- `vreader/Services/DebugBridge/DebugBridgeNotifications.swift` — **17** DEBUG-only names, whole file wrapped in `#if DEBUG` so no symbol reaches Release. See [[Module — debug bridge]].
- `vreader/Services/SettingsNotifications.swift` — 1 name: `.openReadingStatsRequested` (`vreader.settings.openReadingStatsRequested`), posted and observed by `SettingsView` (post at `SettingsView.swift:129`, `.onReceive` at line 152) to present `ReadingDashboardView` (feature #67 WI-4).
- Non-catalog declarations (7, total **83** repo-wide): `BookImporter.swift:30`, `LazyDownloadCoordinator.swift:29+38`, `ProviderProfileStore.swift:196`, `WebDAVServerProfileStore.swift:268`, `OPDSEntryView.swift:182`, `FoliateReaderContainerView+Navigation.swift:51`.

**Naming convention** is `vreader.<scope>.<event>` (e.g. `vreader.debugBridge.openBook`, `vreader.backup.bookFileStateDidChange`). Known deviations, verbatim in code: `com.vreader.ai.providerProfilesDidChange`, `com.vreader.webdav.profilesDidChange`, and two legacy unprefixed names `"opdsBookDownloaded"` and `"foliateEvaluateJS"`.

## Production bus — clusters

**Reader chrome and navigation.** `.readerContentTapped` (bridge → container, toggles chrome), `.readerBookmarkRequested`, `.readerNavigateToLocator` (object = `Locator`; container → format container), `.readerPreviousPage` / `.readerNextPage` (posted by `TapZoneOverlay`; also driven CU-free by the DebugBridge `page` command via `RealDebugBridgeContext+Page.swift:36-37`), `.readerPositionDidChange` (object = `Locator`, feeds the AI panel), `.readerDidClose` (posted by `ReaderLifecycleHelper.swift:160` with the fingerprintKey as object after `recomputeStats`; `LibraryViewObservers.swift:40` refreshes the library — bug #45), `.readerSessionTimeDidChange` (feature #101, `["fingerprintKey", "display"]`, ~once per minute).

**Selection → action pipeline.** A bridge posts `.readerSelectionPopoverRequested` (object = `SelectionPopoverRequestPayload`, or a bare `TextSelectionInfo` decoded tokenlessly — feature #60 WI-7c1/7c5a); `SelectionPopoverActionRouter.route(action:payload:notificationCenter:)` then fans out to `.readerHighlightRequested` (userInfo `"color"` = `NamedHighlightColor.rawValue`), `.readerAnnotationRequested`, `.readerTranslateRequested`, `.readerAskAIRequested` (feature #78, seeds the AI Chat tab), `.readerReadAloudRequested` (feature #78, TTS preempts book reading). Legacy edit-menu paths also post `.readerDefineRequested` / `.readerTranslateRequested` with `TextSelectionInfo` objects.

**Highlights.** `.readerTextSelected` (object = `ReaderSelectionEvent`), `.readerHighlightTapped` (object = `ReaderHighlightTapEvent`; the `sourceRect` contract is host-view-local coordinates per bug #203 / GH #743 — Foliate posts `.zero` and gets the bottom-sheet form), `.readerHighlightEditRequested` (GH #1121 — navigate-then-auto-open-editor with book key + single-flight token; the bridge re-posts `.readerHighlightTapped` with `openInEditMode: true`), `.readerHighlightRemoved` (object = highlight UUID string, bug #78), `.readerHighlightsDidImport` (bug #88), `.searchHighlightClear` (posted by `SearchViewModel`). `.readerAnnotationsDidChange` is the single **mutation-complete** bus (feature #86 WI-2): posted by `PersistenceActor+AnnotationBus.swift:25` after every successful highlight/bookmark/annotation save (unlike the request-time `.reader*Requested` names, which fire before persistence lands); no payload — `ChatAnnotationCache` observes on `.main` and refetches by book key.

**Bottom chrome and More menu (feature #60 WI-6b/6c).** `ReaderBottomChrome` posts `.readerOpenContents` / `.readerOpenNotes` / `.readerOpenDisplay` / `.readerOpenAI`; `ReaderContainerView` observes and presents the matching sheet. The More-menu rows map 1:1 through `ReaderMoreMenuRow.notification` (with inverse `init?(notification:)` as the round-trip source of truth, `ReaderMoreMenuRow.swift:134-151`): `.readerMoreReadAloud`, `.readerMoreToggleAutoTurn`, `.readerMoreBilingual`, `.readerMoreTranslationSettings` (feature #99 — ALWAYS carries and is filtered by `["fingerprintKey": String]`), `.readerMoreReTranslateChapter`, `.readerMoreBookDetails`, `.readerMoreShareBook`, `.readerMoreExportAnnotations`. Since feature #99 every More-menu post carries `userInfo: ["fingerprintKey": String]` when available.

**Bilingual translation (feature #56/#77/#71/#99).** `.readerBilingualDidChange` (`["fingerprintKey"]`), `.readerBilingualPrefetchDidChange` (full `"inFlightUnits": Set<TranslationUnitID>` — authoritative, not a delta, so shimmer never leaks after cancel/retry), `.readerBilingualSectionMaterialized` / `.readerBilingualSectionEvicted` (`["fingerprintKey", "spineIndex"]`, EPUB continuous-scroll, feature #71 WI-7), `.readerBilingualRetry` and `.readerOpenAITranslate` (PDF panel, feature #56 WI-13), `.readerBilingualReTranslateApplied` (`["fingerprintKey", "unit", "segments"]`, WI-15), `.readerBilingualRetranslateStarted` (feature #99 WI-4), `.readerBookTranslationProgressDidChange` (`["fingerprintKey", "completed", "total", "phase"]`) and `.readerBookTranslationTextProviderAvailable` (object = `any ChapterTextProviding`) for whole-book translation (WI-14). See [[Module — bilingual translation]].

**Foliate (AZW3/MOBI) JS-bridge seam.** Pairs of "event out of the WKWebView Coordinator" and "JS-eval request into it", filtered by `fingerprintKey` so concurrent readers don't cross-fire (except the two key-less names at the end of this list): `.foliateSelectionDetected` → `.foliateRequestAnnotationJSCreate` (bug #201 / GH #739), `.foliateAnnotationTapRequested` (feature #53 WI-5), `.foliateRequestAnnotationJSDelete` (bug #199 / GH #733), `.foliateOverlayReadyForSection` (bug #207 / GH #765 — re-paints saved highlights on reopen), `.foliateBilingualBlocksEnumerated` / `.foliateRequestBilingualEvalJS` / `.foliateSectionLoaded` (feature #56 WI-11), `.foliateRelocated` (bug #260 added `fraction` / `sectionTotal` / `tocLabel` for the scrubber), `.foliateRequestSeekFraction` (bug #260 / GH #1130 → `readerAPI.goToFraction`), `.foliateBookReadyTOC` → `.foliateTOCAvailable` and `.foliateRequestSeekTarget` (bug #262 / GH #1136 — live-WebView TOC + row-tap navigation), `.epubFootnoteDetected`, and the legacy `.foliateEvaluateJS` (object = raw JS string, posted by `FoliateReaderContainerView+Navigation.swift`). See [[Module — Foliate AZW3 reader]].

**Services and library.** `.bookDidImport` (`vreader.import.bookDidImport`, `["fingerprintKey"]`; posted by `BookImporter` on both new-row and duplicate-replace paths — bug #197, because `LibraryView` uses an imperative `loadBooks()` array, not `@Query`), `.bookFileStateDidChange` (`["fingerprintKey", "state"]`) and `.libraryRowTappedWhileNotLocal` (`["fingerprintKey", "fileState"]`) from feature #47's `LazyDownloadCoordinator`, `.providerProfilesDidChange` and `.webdavProfilesDidChange` (no userInfo — observers re-fetch, e.g. `loadProfiles()`), `.opdsBookDownloaded` (`["url": URL, "title": String]`, observed at `LibraryViewSheets.swift:73`).

## DEBUG bus (`vreader-debug://` → notifications)

`RealDebugBridgeContext` translates parsed `DebugCommand`s into posts; the invariant posture is **no active observer ⇒ silent no-op** (the bridge never enforces reader presence). Names: `.debugBridgeOpenBook`, `.debugBridgeLibraryChanged`, `.debugBridgeThemeChanged` (bug #144; `"mode"` is always a canonical `ReaderThemeV2` rawValue — bug #206), `.debugBridgeTTSCommand` (feature #45 WI-4c-b), `.debugBridgeSearchCommand` (bug #238), `.debugBridgeBilingualCommand` (feature #77), `.debugBridgeHighlightCommand` (bug #237; `[start, end)` UTF-16 semantics), `.debugBridgePresentSheet` (bug #253; `detent` bug #256), `.debugBridgeAIAction` (bug #255 — invokes the SAME view-model paths the buttons do), `.debugBridgeSeekFraction` (bug #267), `.debugBridgeScrollSheet` (bug #271), `.debugBridgeNavigateCommand` (bug #273 / feature #71 WI-8), `.debugBridgeScrollBoundaryCommand` (feature #71 WI-6b — bypasses the rAF-paused scroll observer), `.debugBridgePDFHighlightCommand` (feature #17), `.debugBridgeSetLayoutCommand` (feature #75 WI-5a), `.debugBridgeRenderedTextChanged` (bug #276 / GH #1218) and `.debugBridgeLandingBloomChanged` (feature #74 — both posted by readers TO the bridge probe, the reverse direction). The `provider` command (bug #243) deliberately has NO bridge notification — it mutates `ProviderProfileStore`, which posts the production `.providerProfilesDidChange` itself.

## Edge cases and invariants

- **fingerprintKey filtering** is the standard defense against concurrent readers cross-firing; every modern Foliate seam (not the legacy `.foliateEvaluateJS` or `.epubFootnoteDetected`) and every feature-#99+ More-menu post carries it.
- **Observer teardown is mandatory** (project convention in `.claude/rules/50-codebase-conventions.md`): `removeObserver` in `defer` (tests) or `deinit`/`.onDisappear` (views/coordinators).
- **DEBUG names never ship**: `DebugBridgeNotifications.swift` is file-scope `#if DEBUG`; `scripts/verify-release-no-debugbridge.sh` gates Release.
- **Request-time vs mutation-complete**: `.reader*Requested` fires before async persistence; `.readerAnnotationsDidChange` fires only after a successful save.
- **Legacy producer tolerance**: `resolveHighlightColor` defaults missing/non-String `"color"` to `"yellow"`; `SelectionPopoverRequest.payload(from:)` accepts a bare `TextSelectionInfo` object.
- `docs/architecture.md` carries a "Notification Bus" table (section header at line 286) that mirrors this catalog; the doc-sync rule requires updating it whenever a bus name is added.
