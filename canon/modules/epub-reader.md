# Module — EPUB reader

## Purpose

Renders EPUB books. Two engines coexist: the **legacy custom WKWebView bridge** (`EPUBWebViewBridge`, `ReaderEngine.epubWKWebView`) and the **Readium Swift Toolkit navigator** (`ReadiumEPUBHost`, `ReaderEngine.epubReadium`, feature #42). `ReaderEngine.routeEPUB(readiumFlagEnabled:layout:)` (`vreader/Models/ReaderEngine.swift`) picks per open: flag OFF → legacy for both layouts; flag ON (default ON since the WI-14 G2 flip 2026-06-01) → Readium for **paged**, legacy for **scroll** — because Readium's per-resource paginator has an inherent chapter-boundary seam in scroll mode, the feature-#71 continuous stitch handles scroll (feature #85 "approach C"). This dossier covers the parser service and the legacy bridge in depth; see [[Architecture — reader dispatch and format hosts]] for dispatch context.

## Key files and types

Parsing service (`vreader/Services/EPUB/`):
- `EPUBParser.swift` — `actor EPUBParser: EPUBParserProtocol`. Selective extraction: on `open(url:)` extracts only `META-INF/container.xml` + OPF + first chapter + nav/ncx into a persistent cache `Caches/EPUBCache/{name}-{size}-{modDateInt}/`; CSS/fonts pre-extract in a detached `.utility` task; other chapters extract on demand in `contentForSpineItem(href:)`. Parses container.xml/OPF/nav.xhtml/toc.ncx with Foundation `XMLParser` delegates (`ContainerXMLDelegate`, `OPFXMLDelegate`, `NavXHTMLDelegate`, `NCXDelegate`).
- `EPUBParserProtocol.swift` — `open/close/contentForSpineItem/resourceBaseURL/extractedRootURL/isOpen`; `EPUBParserError` enum.
- `EPUBTypes.swift` — `EPUBMetadata`, `EPUBSpineItem`, `EPUBPosition` (clamped progressions), `ReadingDirection` (ltr/rtl/auto), `EPUBLayout`. `EPUBMetadata.withResolvedTitles(_:)` nils un-nav'd spine titles so "Section N" placeholders survive only nav-less EPUBs (bug #321).
- `ZIPReader.swift` — `actor ZIPReader`: read-only ZIP via the Compression framework (`COMPRESSION_ZLIB`), memory-mapped `Data(.mappedIfSafe)`, methods 0/8 only, zip-slip path validation.
- `EPUBFileLoader.swift` — `EPUBFileLoader.load(url:parser:positionStore:bookFingerprintKey:)` = parse + tolerant position restore.
- `EPUBScrollAnchorResolver.swift` — `matchIndex(forStoredHref:spineHrefs:)`: exact → path-component-boundary suffix → percent-decoding-normalized unique match (bug #349, cross-engine href forms incl. CJK percent-encoding).
- `EPUBPreExtractor.swift` — full extraction at import time (fire-and-forget), same cache key.
- `EPUBComplexityClassifier.swift` / `EPUBTextStripper.swift` — simple-vs-complex HTML classification and XHTML→NSAttributedString (legacy Unified-reflow era, WI-B07).
- `FoliateJS/` — vendored foliate-js (MIT) adapted for WKWebView: `foliate-bridge.js` (379 lines; CFI, SVG Overlayer, text-walker, TTS SSML, footnote detection, all under `window.__foliate`), plus source modules `epubcfi.js`, `overlayer.js`, `tts.js`, `footnotes.js`, `text-walker.js`.

Legacy bridge (`vreader/Views/Reader/`):
- `EPUBWebViewBridge.swift` — `UIViewRepresentable` that `loadFileURL(contentURL, allowingReadAccessTo: baseDirectory)` per chapter; injects user scripts and registers message handlers via a `WeakScriptMessageHandler` proxy (breaks the WKUserContentController retain cycle). `outerScrollEnabled(isPaged:hasContinuousConfig:)` collapses to ONE vertical scroller (bug #327 / GH #1561 — code comments cite the GH number).
- `EPUBWebViewBridgeCoordinator.swift` — `WKScriptMessageHandler` + `WKNavigationDelegate`; `decidePolicyFor` cancels any non-`file://` URL and any path outside `allowedRoot`; `didFinish` injects theme CSS, sets up pagination or continuous bootstrap, registers the DebugBridge registry binding (`fingerprintKey` + `readerToken`, bugs #126/#142) and a 2s DEBUG "early settle fallback" (bug #251).
- `EPUBWebViewBridgeJS.swift` — theme inject/remove (`#vreader-theme` style element), `scrollToFractionJS`, `viewportLockJS` (bug #279), `langInjectionJS` (bug #336, BCP-47 charset sanitized), `cssPreprocessJS` (rewrites `-epub-*`, `page-break-*` → `break-*`), `progressTrackingJS` (100ms-throttled scroll → `progressHandler`), safe-area/scroll-lock/background seams (bugs #163/#167/#279/#348).
- `EPUBPaginationHelper.swift` — CSS multi-column paged mode: `column-count: 1 !important` + `column-width`/`gap: 40` (bug #171 newspaper fix), `navigateToPageJS` via `scrollLeft`, `totalPagesJS = ceil(scrollWidth/viewportWidth)`, `pagedSwipeTrackingJS` (bug #281).
- `EPUBPageAxisProbe.swift` + `EPUBSwipeGestureClassifier.swift` — computed writing-mode/direction probe before pagination CSS; RTL/vertical page-axis (feature #75).
- `EPUBHighlightBridge.swift` / `EPUBHighlightJS.swift` — selection + highlight JS (below).
- `EPUBContinuousScrollBridge/JS/Coordinator.swift`, `EPUBChapterBodyRewriter.swift`, `EPUBWebViewEvaluatorHandle.swift` — feature #71 continuous scroll (below).
- `EPUBReaderContainerView.swift` (941 lines, + `+Navigation`/`+ChapterWrap` extensions) — SwiftUI container: chrome, progress, seek, highlights, bilingual state. `ReaderFormatHosts.swift` `EPUBReaderHost` owns `EPUBReaderViewModel` + `EPUBParser` `@State` and closes them in host `.onDisappear` (bug #252).
- `SelectionMenuSuppressingWebView.swift` — `buildMenu(with:)` removes all standard edit menus so the designed selection card is the sole surface (bug #339 sibling).
- `ReadiumEPUBHost.swift` (+ ~10 extensions) — Readium `EPUBNavigatorViewController` host: envelope position restore (`VReaderLocatorPersisting` dual-write), decoration-based highlights, bilingual per-spine inject, TTS follow, bottom chrome (bug #299).
- `vreader/ViewModels/EPUBReaderViewModel.swift` — `@Observable @MainActor`; delegates to `EPUBFileLoader`, `ReaderPositionService` (2s debounced saves), `ReaderLifecycleHelper`.

## JS message protocol (legacy bridge)

WKScriptMessage channels registered in `makeUIView`: `progressHandler` (Double scroll fraction; legacy single-chapter mode only), `continuousScrollHandler` + `sectionMaterialized` (continuous mode replaces `progressHandler`), `contentTapHandler` (`{x, w}` → `ReaderTapZoneRouter` → `.readerNextPage`/`.readerPreviousPage`/`.readerContentTapped`; a bare `'tap'` — no coordinates — bypasses the router and posts `.readerContentTapped` directly, bug #239), `pagedSwipeHandler` (`{dx, dy}` → `EPUBSwipeGestureClassifier`), `selectionChanged` (XPath-serialized range + rect + optional `sectionHref`), `footnoteHandler` (→ `.epubFootnoteDetected`), `highlightTapHandler` (`{id, rect}` → `.readerHighlightTapped`, feature #53 WI-4/#64 WI-8), and `EPUBBilingualJS.enumerateMessageHandlerName` (feature #56 WI-10). `EPUBScrollBoundarySignal.parse`/`EPUBSectionMaterialized.parse` reject bool-backed `NSNumber` via `CFGetTypeID == CFBooleanGetTypeID()` — bug #327: `as? Bool` conflated JS `0` with `false` and stuck the continuous window at the cover.

**JS bridge channels, by engine.** Legacy bridge: `EPUBWebViewBridge.Coordinator` (the nested type defined via extension in `EPUBWebViewBridgeCoordinator.swift`) is the real `WKScriptMessageHandler` conformer — it owns `userContentController(_:didReceive:)` and dispatches every channel above; it is registered indirectly through the `WeakScriptMessageHandler` proxy declared in `EPUBWebViewBridge.swift` (line 27) so `WKUserContentController`'s strong retain can't cycle back to the coordinator. JS evaluation on the legacy side runs through `EPUBWebViewEvaluatorHandle`'s late-bound `weak` `WKWebView` reference, and results are consumed by call sites such as `EPUBReaderContainerView+DebugBridgeHighlight.swift`. `EPUBWebViewBridgeJS.swift`, despite the name, is **not** a `WKScriptMessageHandler` conformer — it's a static JS-generator + lifecycle/cleanup extension (`removeScriptMessageHandler` calls for teardown). Readium engine: the boundary-scroll handler is `ReadiumBoundaryScrollProxy` (`ReadiumEPUBHost+ContinuousScroll.swift`), a WEAK proxy registered directly on the Readium **navigator**-managed, per-spread `WKUserContentController` — there is no bridge-owned `WKWebView` to register against. JS evaluation instead goes through the navigator's own `evaluateJavaScript` surface, called from `ReadiumReaderCoordinator` and its `+Transparency`/`+SelectionStyle`/`+Replacement` extensions (`navigator.evaluateJavaScript(...)`) — architecturally distinct from the legacy bridge's direct-ownership model.

## Pagination and continuous scroll

Paged mode: `setupPagination` probes the page axis (`EPUBPageAxisProbe.computedStyleJS`, feature #75), injects `#vreader-pagination` CSS, queries page count after a 0.2s layout settle, all guarded by a monotonic `paginationGeneration` token; reopen converts the persisted fraction to a page via `onPaginationReady(totalPages, resumeFromFraction)` (bug #293).

Continuous scroll (feature #71, scroll layout): one file-backed bootstrap document (`__vreader_continuous_bootstrap.html` written into the extracted root; `loadHTMLString` can't read `file://` subresources) with an inner `#vreader-scroll-root` column. `EPUBChapterBodyRewriter` rewrites each chapter (extract body, absolutize URLs, namespace `id`s/#fragments by spine index, scope CSS under `[data-vreader-spine-index="N"]`); `EPUBContinuousScrollCoordinator` (`@MainActor`) materializes/evicts a chapter window through an async-throwing evaluator (`EPUBWebViewEvaluatorHandle`, weak late-bound WKWebView — window never advances on failed eval). The rAF observer posts `{visibleSpineIndex, intraFraction, nearTop/BottomBoundary, pxAbove, pxBelow, sectionHeights, touchActive}` with `prefetchPx = 800`; evictions/prepends defer while `touchActive` (bug #329), with `touchGrowthHardCapSlack = 47` and `maxEvictionsPerExtend = 2` (bug #347 chained-fling fixes). Whole-book progress = `EPUBProgressCalculator.progress` = `(spineIndex + scrollFraction) / totalSpineItems`.

## Highlights and selection

`EPUBHighlightJS.selectionTrackingJS` debounces `selectionchange` 300ms, serializes XPath paths that skip `data-vreader-decoration` nodes (so bilingual inserts don't shift anchors), clamps cross-section drags to the start section, and posts to `selectionChanged`. `highlightAPIJS` exposes `window.__vreader_createHighlight` / `_createHighlightInSection` / `_createHighlightInSectionByQuote` / `_removeHighlight` / `_clearAllHighlights`: CSS Highlight API primary with foliate SVG `Overlayer` fallback (bug #159 flipped the order). Search-result flash (`searchHighlightJS`, bug #43) polls `window.find()` 40×50ms with a generation token (bug #182 round-3). Anchors persist as `AnnotationAnchor.epub(href:cfi:serializedRange:)`; quote-only ranges are Readium-created highlights re-anchored by quote (feature #85 WI-2). See [[Module — annotations and highlights]].

## JS-injection safety and CSS/theme injection

Every interpolated value goes through `FoliateJSEscaper.escapeForJSString` (`vreader/Services/Foliate/FoliateJSEscaper.swift`): escapes `\`, `'`, `\n`, `\r`, `\t`, U+2028, U+2029 (bugs #135/#136 consolidated EPUB + Foliate escaping; U+2028/2029 broke CJK search highlights). Companions: `escapeForCSS` (strip-list), `sanitizeCSSColor`, `sanitizeFlow` allowlist, `clampFontSize` 8–72. Theme CSS injects as `#vreader-theme` `<style>` via `createElement + textContent` (never innerHTML); continuous mode live-reinjects on change via `continuousThemeReinjectJS` (bug #278). `langInjectionJS` sanitizes to `[A-Za-z0-9-]`. Divider titles are HTML-escaped then JS-escaped. The rewriter deliberately does NOT sanitize `<script>`/`on*=` — EPUB content is the same trusted-local-file model as the paged `loadFileURL` path. Navigation policy: `file://` only, prefix-checked against `allowedRoot` with a trailing-slash pin; `EPUBParser.validateContainment` does the same server-side (path-traversal guard).

## Edge cases and invariants

- Actor reentrancy guard `_isOpening` in `EPUBParser.open`; UTF-8 → Latin-1 decode fallback for chapter content.
- WKWebView resets contentOffset after every `loadFileURL`; chapter-top restore uses native `contentOffset.y = -safeAreaTopInset`, not JS `scrollTo(0,0)` (bug #163 reopen), with URL-guards against rapid chapter navigation.
- Deferred `pendingHighlightJS` is stashed on the coordinator when contentURL changes in the same SwiftUI update and evaluated in `didFinish` (bug #182); the non-nil stash is the in-flight sentinel against double-eval.
- Swipe/tap dedup: JS `__vreaderSwipeConsumedTap` flag with per-swipe expiry timer swallows WebKit's synthetic post-swipe click (double-advance/link-activation, bug #281).
- Empty spine throws `parsingFailed("No spine items found in OPF")`; empty selection/whitespace-only text rejected in `parseSelectionMessage`; degenerate cross-section clamp rejects the popover.
- Pagination CSS marks all paging directives `!important` so book CSS can't miscount pages; column-width clamps ≥1px for Stage-Manager resize storms (bug #171).
