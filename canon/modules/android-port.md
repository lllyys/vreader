# Module — Android port

## Purpose

A second, independently-shippable native vreader app (Kotlin + Jetpack Compose) under `android/`, sharing identity/library/backup contracts with iOS but not code (see [[Decision — Android port strategy]]). It reads EPUB/TXT/MD/PDF/AZW3, imports via SAF with content-hash dedup, resumes positions cross-device via the canonical Locator, and backs up/restores against WebDAV in the exact iOS materializing-restore layout — so "your library follows you across devices" holds across platforms.

## Module layout and toolchain

- `android/` is a self-contained Gradle root (`rootProject.name = "vreader-android"`, `android/settings.gradle.kts`) with two modules: `:app` (`android/app/`, namespace + applicationId `com.vreader.app`) and `:identity` (`android/identity/`, pure Kotlin/JVM — the shared contracts module both `:app` and the conformance lane consume; see [[Module — cross-platform contracts]]).
- Toolchain pinned to the Spike-B-verified set (`android/build.gradle.kts`): AGP 8.13.2, Kotlin 2.3.20, Gradle 8.14.4 wrapper, compileSdk 36, minSdk 26, targetSdk 36, JDK 17, KSP 2.3.9, Compose BOM 2024.09.03, Room 2.8.4, Readium Kotlin Toolkit 3.3.0 (`readium-shared`/`readium-streamer`/`readium-navigator`), kotlinx-serialization-json 1.7.3, androidx.webkit 1.16.0, DataStore 1.1.1, Robolectric 4.13; core-library desugaring mandatory (Readium 3.3.0 links against it).
- Version source of truth: `android/version.properties` (`versionName=0.13.11`, `versionCode=84` at capture); read config-cache-safely via `providers.fileContents` in `android/app/build.gradle.kts`. Android tags are `android/vX.Y.Z` (latest at capture: `android/v0.13.11`); iOS keeps plain `vX.Y.Z` per `.claude/rules/40-version-bump.md`.
- Scale at capture: 121 main `.kt` files in `:app`, 73 JVM-test, 40 androidTest, 14 in `:identity`.

## Feature package behavior

- `ai/` — `AiProviderStore` persists provider profiles (DataStore JSON + `SecretCipher`-wrapped key) with a request-start `snapshot()`; `AiProviderFactory` builds the matching `AiClient` from that snapshot; `AiSettingsViewModel`/`AiProviderListScreen`/`AiProviderEditSheet` drive the provider list + editor with a live (unsaved-form) Test Connection; `AiChatViewModel`/`AiChatPanel` stream chat answers and cache per-chapter summaries keyed on book+chapter+digest+provider+model+prompt-version; `AiMarkdownRenderer` degrades partial/streaming markdown to literal text rather than crashing. Key never logged.
- `opds/ui/` — `OpdsSourcesViewModel`/`OpdsSourceListScreen`/`OpdsAddSheet` manage the catalog list + add/edit form (live Test Connection against an unsaved client); `OpdsBrowseViewModel`/`OpdsBrowseScreen` fetch a feed, split it into navigation rows vs. acquisition entries, track per-entry download→import state, and follow pagination; `OpdsErrorView` maps failures to offline/auth/not-found views.
- `backup/` UI — `BackupViewModel` holds backup/restore state under Gate-2 rules (one coalesced backup job, a load that cancels its predecessor, one-shot effects via `Channel`); `BackupRestoreScreen`/`BackupScaffold`/`WebDavServersScreen`/`ServerEditSheet` render the designed states; `RestoreFlow` is the stateless confirm→progress→result flow ("nothing is deleted"); `SelectiveRestoreSheet` is the per-book local/remote/downloading/failed picker.
- `tts/` — `TtsChunker` splits decoded text into speakable sentences carrying raw-text char spans; `TtsVoiceFilter` filters and deprioritizes (never hard-drops) low-quality voices per locale; `TtsHighlight` maps a spoken sentence's span onto a reader chunk's local span for the read-aloud wash; `TtsViewModel` is the transport state machine (Started drives sentence advance, Range only refines the current highlight, a generation token guards stop/start races); `TtsControlBar`/`TtsVoiceSheet`/`TtsSpeedSheet` are the designed controls.
- `reader/` selection — `TxtSelection`/`TxtSourceOffsets` are pure SOURCE-space (UTF-16) range math shared by selection and highlighting; `TxtSelectionController` converts a pointer hit through chunk-local space to a SOURCE offset and resolves word-boundary long-press; `TxtHighlightHitTester`/`TxtHighlightWash` resolve tap-to-highlight (newest-wins) and paint stored highlights as washes; `ReaderHighlightController` wraps Readium's `SelectableNavigator`/`DecorableNavigator` for EPUB selection + decorations.

These packages (incl. their Compose screens) are exercised by the 73 JVM tests (e.g. `AiProviderStoreTest`, `OpdsBrowseViewModelTest`/`OpdsSourcesViewModelTest`, `BackupViewModelTest`, `TtsChunkerTest`/`TtsVoiceFilterTest`, `TxtSourceOffsetsTest`) and 40 instrumentation tests — not itemized per file in this dossier.

## Data flow

SAF `OpenDocument` picker (`MainActivity.kt`) → `BookImporter` copies bytes into app-private `filesDir/books` and fingerprints THOSE bytes (`vreader.contracts.DocumentFingerprint` streaming 64KB tee — converter-independent identity) → Room upsert keyed on `fingerprintKey` (dedup preserves the saved position) → the Library screen (`LibraryViewModel` StateFlow) routes opens by `originalFormat` to the per-format reader Activity → each reader saves a `VReaderLocator` envelope (engine + `readiumLocatorJSON` + canonical `legacyLocator`) through `LibraryRepository` → backup collects sections + content-addressed blobs to WebDAV; restore re-fingerprints and re-imports.

## Concurrency

Coroutines + structured concurrency (the actor/`@MainActor` analog per `.claude/rules/50-codebase-conventions.md` §12): repos take injected `CoroutineDispatcher`s (`BookOpener(ioDispatcher = Dispatchers.IO)` — "never parse a 13–18MB EPUB on Main"), UI is `StateFlow` collected lifecycle-aware, `FoliateBridge` is `@MainThread`-annotated, `PdfDocument` serializes `PdfRenderer` access with a Mutex, and `AppContainer.appScope` outlives screens for fire-and-forget position flushes.

## Edge cases and invariants

- Positions store the ENVELOPE, never a bare Locator (#106 Gate-2 Critical) — survives engine swaps and cross-device restore.
- `HighlightEntity.locatorJSON` is the round-trippable plain `Locator`; the backup wire form must be `locator.canonicalJson()` — never copy the column verbatim.
- Migration DDL must match Room's generated schema exactly; the migration round-trip test (`VReaderDatabaseMigrationTest`) opens the real DB whose PRAGMA validation catches drift.
- WebView security (#126): no `file://`, no remote loads, origin-allowlisted message channel, book scripts neutered by the bundle patch + shell CSP (origin separation would NOT isolate them — foliate's section documents are shell-origin `blob:` URLs).
- Test gates run ONLY through `scripts/run-android-tests.sh` / `scripts/run-android-verify.sh` (watchdogged; a killed bare Gradle orphans the daemon — rule 52 Cause D). Unit tests JVM/Robolectric; `--add-opens java.base/java.net` for the WebDAV verb-fallback test (#116).
- Stats rows deliberately have no FK to `books`: orphans of deleted books still count toward window totals.
