# Module — PDF reader

## Purpose

Renders `.pdf` books via PDFKit's `PDFView` (system framework, no third-party dependency): page-based reading with position persistence and session tracking, password unlock for encrypted PDFs, non-destructive highlights stored in SwiftData (never written into the PDF file), search-result flash highlighting, theme-tinted gutter, a page-snapping scrubber, and (feature #56 WI-13) a below-page bilingual translation panel — PDF is fixed-layout, so the interlinear renderer used by EPUB/Foliate/TXT/MD does not apply.

## Key files and types

- `vreader/Views/Reader/ReaderFormatHosts.swift` — `struct PDFReaderHost: View`. Owns `PDFReaderViewModel` via `@State`; its `.task` builds `PersistenceActor(modelContainer:)` + `ReadingSessionTracker(clock: SystemClock(), store: SwiftDataSessionStore(...), deviceId: ReaderContainerView.deviceId)`. `settingsStore: ReaderSettingsStore?` is optional (bug #198 threading kept previews source-compatible).
- `vreader/Views/Reader/PDFReaderContainerView.swift` (362 lines) — container. The `PDFViewBridge` is ALWAYS mounted; loading/password/error are separate ZStack sibling overlays (accessibility ids `pdfReaderLoading`, `pdfReaderError`, `pdfPasswordField`; content is `pdfReaderContent` inside `pdfReaderContainer` — bug #214 / GH #834 scoped the container identifier so it stops clobbering `ReaderBottomChrome`'s button ids).
- `vreader/Views/Reader/PDFViewBridge.swift` (552 lines) — `struct PDFViewBridge: UIViewRepresentable` over `PDFView` (`autoScales = true`, `displayMode = .singlePageContinuous`, `displayDirection = .vertical`, id `pdfView`). Inner `@MainActor final class Coordinator: NSObject, UIGestureRecognizerDelegate`. `static func applyThemeIfChanged(pdfView:theme:lastAppliedTheme:) -> ReaderThemeV2?` tints the gutter (bug #198); page interiors are NOT inverted. `ReaderScrollIndicatorPolicy.hideIndicators(in:)` hides the wrapped scroller (bug #348).
- `vreader/ViewModels/PDFReaderViewModel.swift` — `@Observable @MainActor final class PDFReaderViewModel`. Zero-based `currentPageIndex`, `totalPages`, `needsPassword`, `isDocumentLoaded`; delegates to `ReaderLifecycleHelper` + `ReaderPositionService` (default save debounce 2_000_000_000 ns). `makeCurrentLocator()` uses `LocatorFactory.pdf(fingerprint:page:totalProgression:)` with a `.repairedForCanonicalization()` fallback (#109 WI-2).
- `vreader/Views/Reader/PDFPageNavigator.swift` — `@MainActor final class PDFPageNavigator: BasePageNavigator`; adds `syncCurrentPage(_:)` (PDFView-reported page changes) vs the inherited tap-zone `nextPage`/`previousPage`. Holds NO `PDFView` reference (pure unit testing).
- `vreader/Views/Reader/PDFProgressHelper.swift` — `enum PDFProgressHelper`, pure statics: `progressForPage`, `pageForSeekValue`, `pageLabel` ("Page X of Y"), `discreteSteps(totalPages:) = totalPages - 1`, `shouldShowProgressBar`.
- `vreader/Views/Reader/PDFAnnotationBridge.swift` — `enum PDFAnnotationBridge`, pure statics: `normalizeRects`/`denormalizeRects` (0–1 page-relative rect storage, zoom-independent), `isValidRect` filters non-finite/negative rects (bug #56), `colorForName` (yellow/blue/green/pink/orange/purple at alpha 0.3, default yellow), `makeSelectionEvent` (→ `AnnotationAnchor.pdf(page:rects:)`), `createHighlightFromAnchor`, `restoreHighlights -> [UUID: [PDFAnnotation]]`.
- `vreader/Views/Reader/PDFHighlightRenderer.swift` — `@MainActor final class PDFHighlightRenderer: HighlightRenderer`. `weak var document: PDFDocument?`; `annotationMap: [UUID: [PDFAnnotation]]` exists because PDFKit has no lookup-by-ID API (delete fix, bug #87). `setDocument(_:)` clears the map only on identity change. `restore(records:forHref:using:)` ignores href/evaluator (EPUB-specific params).
- `vreader/Views/Reader/PDFHighlightTapResolver.swift` — `resolveHighlightID(atPagePoint:onPage:annotationMap:)` plus the tolerance-aware `resolveHighlightIDWithTolerance` (bug #287 / GH #1268: a one-text-line annotation is under Apple's 44pt target; `HighlightHitTolerance` expands rects, exact hits win first).
- `vreader/Views/Reader/PDFPasswordPromptView.swift` — `SecureField` prompt with error line; submit bumps `passwordAttemptId` so retrying the SAME password re-attempts unlock.
- Extensions: `PDFReaderContainerView+Overlays.swift` (overlays + `bottomOverlay` mounting `ReaderBottomChrome` with `discreteSteps` page snapping and the feature #101 "N pages left in book" readout), `+Highlights.swift` (`handleHighlightAction(event:container:color: String = "yellow")` — the PDF dialog has no color picker), `+Bilingual.swift` (feature #56 WI-13 panel via `.safeAreaInset(edge: .bottom)`; `PDFKit autoScales` reflows for the reduced height), `+DebugBridgePDFHighlight.swift` (DEBUG-only `pdf-highlight` verification observer reading the renderer's live unlocked `document`).
- `vreader/Services/Reader/PDFChapterTextProvider.swift` — `struct PDFChapterTextProvider: ChapterTextProviding` (Sendable). Translation units are zero-indexed inclusive page ranges encoded `"start-end"` (`kind: .pdfPageRange`), grouped by `pagesPerUnit` (default 1). `PDFDocument` is not Sendable, so it is opened lazily inside each call.

## Dependencies

Internal: `PersistenceActor` through `ReadingPositionPersisting` / `HighlightPersisting` boundaries; `HighlightCoordinator` (persists then calls `renderer.apply`); `ReaderBottomChrome` + `PDFProgressHelper` for the scrubber; `ReaderTapZoneRouter` for tap grammar; `LocatorFactory`; `ReaderSettingsStore` for theme + layout preference (`epubLayout` drives the bug #239 paged tap routing) but never font size — `FontSizeCalibrator` intentionally excludes PDF as a target (feature #70). External: PDFKit, UIKit, SwiftUI, SwiftData. See [[Module — annotations and highlights]], [[Module — locator]], [[Module — bilingual translation]].

## Data flow

Dispatch (`ReaderEngine.resolve` → `.pdfKit`, see [[Architecture — reader dispatch and format hosts]]) → `PDFReaderHost` → `PDFReaderContainerView` → `PDFViewBridge`. Document load runs in `Task.detached` (`PDFDocument(url:)`) then hops to `MainActor.run`; a locked document routes to `viewModel.documentNeedsPassword()`. Page change: PDFKit posts `.PDFViewPageChanged` → `Coordinator.pageDidChange` → `viewModel.pageDidChange(to:)` → container `.onChange(of: viewModel.currentPageIndex)` updates progress, syncs `PDFPageNavigator`, and posts `.readerPositionDidChange` with a `Locator` (feeds the AI panel + DebugBridge probe). Selection: `.PDFViewSelectionChanged` → per-line rects normalized → `ReaderSelectionEvent` posted on `.readerTextSelected` → `confirmationDialog` (Highlight / Add Note / Copy). Tap: highlight hit-test first (`.readerHighlightTapped` → unified popover, feature #64 WI-7), else `ReaderTapZoneRouter.dispatch` — in `.paged` layout side zones post `.readerNextPage`/`.readerPreviousPage` (bug #239), otherwise `.readerContentTapped` toggles chrome. Search navigation: `.readerNavigateToLocator` with `locator.page` + `textQuote` → `document.findString(_:withOptions: .caseInsensitive)` filtered to the target page, selection auto-clears after 3.0 s via a cancellable `DispatchWorkItem` (bug #43). Also observes `.readerBookmarkRequested`, `.readerHighlightsDidImport` (bug #88 re-render), `.readerHighlightRemoved` (bug #87 coordinator removal). TOC: `ReaderTOCFactory.buildTOCDetailed` case `"pdf"` extracts the `PDFOutline` tree off-main via `Task.detached`.

## Concurrency

ViewModel and bridge Coordinator are `@MainActor`; document I/O is detached; `close()`/`onBackground()` run inside `UIApplication.beginBackgroundTask` so the debounced position save completes before suspension. Close ordering is load-bearing: saveNow → recordProgress → end → stats → notify (bugs #34, #45).

## Edge cases and invariants

- Empty PDF (0 pages): `totalProgression == nil`, `pageIndicator == "0 / 0"`, progress bar hidden; single-page docs report progress 1.0.
- Every restore/highlight/search mutation in `updateUIView` is gated on `!document.isLocked`; page indices clamp via `clampPage` / navigator clamping.
- Highlight rects with non-finite or negative dimensions are filtered before `PDFAnnotation` creation (bug #56 crash guard).
- `pagesPerHour` returns nil under 60 s of session time or 0 distinct pages.
- Overlapping highlights: first matching UUID wins (dictionary order unspecified); tolerance hit-test still enforces page identity and never captures taps far outside a tall annotation.
- `PDFChapterTextProvider.unit(containing:)`: negative page → nil; page past the last unit clamps to the last unit; unreadable PDF yields `[]` units, not a throw.
- PDF capabilities (`FormatCapabilities` case `.pdf`): `.textSelection, .highlights, .nativePagination, .annotations` + universal `.search, .bookmarks` — "PDF never gets TTS or unifiedReflow" (the More-menu Read-aloud row is gated off).
