# Module — Foliate AZW3 reader

## Purpose

Renders Kindle-family books (`.azw3`, plus `.azw`/`.mobi`/`.prc` folded into `BookFormat.azw3`) in a `WKWebView` driven by the vendored Foliate-js bundle. The live host chain is [[Architecture — reader dispatch and format hosts]] → `ReaderContainerView` `case .foliateWeb:` (vreader/Views/Reader/ReaderContainerView.swift:1246) → `FoliateBilingualContainerView` (the feature #56 WI-11 live-container wrapper) → `FoliateSpikeView` (the proven spike: `loadHTMLString` + inline IIFE bundle + base64 book handoff). This dossier covers the Foliate/AZW3 lane specifically — the Readium-based EPUB implementation (`ReadiumEPUBHost` + extensions, `ReadiumNavigatorRepresentable`, `ReadiumDecorationHighlightAdapter`, `ReadiumBilingualCommander`/`EvalAdapter`/`ChapterTracker`, `ReadiumEPUBReaderViewModel`) is documented separately in [[Module — EPUB reader]].

## Data flow

1. `makeUIView` reads the book file as base64, builds an HTML shell embedding `foliate-bundle.js` inline, `loadHTMLString(_:baseURL: nil)`.
2. JS posts `bridge-ready` → `Coordinator.openBook()` evaluates an async IIFE: `atob` → `Uint8Array` → `File` → `readerAPI.open(file)`.
3. `book-ready` → `onBookReady(title)`; if the parsed TOC is non-empty, posts `.foliateBookReadyTOC` (fingerprintKey-scoped); then runs the init IIFE: `await readerAPI.init({})`, `setLayout({flow: window.__vreaderTargetFlow})`, `setStyles(window.__vreaderTargetThemeCSS)`, `post('layout-ready')`. Only `layout-ready` flips `isBookReady` (bug #189 race: `evaluateJavaScript`'s completion fires at Promise *creation*, not resolution — hence message-post + JS-side globals for mid-init layout/theme changes).
4. `relocate` (the render-complete signal) → `.foliateRelocated` (`sectionIndex`, `sectionTotal`, `fraction`, `tocLabel?`, `tocHref?`) + `.readerPositionDidChange` (object: `Locator` from `FoliateNavSeek.positionLocator`, `fraction` → `progression` so `AIContextExtractor` works — bug #262). DEBUG: marks the reader settled in `DebugReaderRegistry` ([[Module — debug bridge]]).
5. `tap` with `{x, w}` → `ReaderTapZoneRouter.dispatch` (paged: side zones → `.readerNextPage`/`.readerPreviousPage`, bug #239) else `.readerContentTapped` (chrome toggle).
6. Container relays: `.readerNavigateToLocator` → `FoliateNavSeek.navigationTarget` → `.foliateRequestSeekTarget`; scrubber → `.foliateRequestSeekFraction`; `.foliateBookReadyTOC` → `FoliateTOCConverter.convert` → `.foliateTOCAvailable`.
7. Coordinator observers (all `queue: .main` + `MainActor.assumeIsolated`, all removed in `deinit`): `.foliateRequestAnnotationJSDelete`/`Create`, `.foliateRequestBilingualEvalJS`, `.readerNextPage`/`.readerPreviousPage` (global, unfiltered), `.foliateRequestSeekFraction`, `.foliateRequestSeekTarget` (both fingerprintKey-filtered).

## Theming and layout

`FoliateSpikeView.themeCSS(for:)` composes `FoliateStyleMapper.themeCSS` (font size routed through `FontSizeCalibrator.calibratedFoliateSize(forUnified:)`, feature #70 WI-4) + theme paper/ink colors (feature #93 — **Photo theme excluded**, its alpha paper would bleed the publisher background image) + bilingual block CSS (bug #304) + loading-shimmer CSS (feature #77) + `::selection` wash (bug #340). Host shell: `isOpaque = false` + theme `backgroundColor` as the defensive frame fill (feature #93). Layout flow (`paginated`/`scrolled`, bug #189) toggles `scrollView.isScrollEnabled` and diffs independently from theme CSS in `updateUIView` (a guard-early-return there dead-coded the font slider once).

## Concurrency

Coordinator is used on the main actor (`handleMessage` is `@MainActor`; observers hop via `MainActor.assumeIsolated`); observer tokens are `nonisolated(unsafe)` because `deinit` is nonisolated. `extractPlainText()` uses `callAsyncJavaScript` (awaits the Promise) raced against a 12s timeout task group so a wedged WebKit render can never hang TTS. `FoliateChapterTextProvider` is an `actor` bridging the `@MainActor` `FoliateSectionExtracting` facade into the `Sendable` `ChapterTextProviding` boundary ([[Module — bilingual translation]]).

## Edge cases and invariants

- CSS-string interpolations (`setStylesJS`, the init IIFE's theme-CSS seed) route through `FoliateJSEscaper.escapeForJSString` (single quote, backslash, newlines, U+2028/U+2029). Not universal: `openBook()` interpolates `bookBase64`/`bookExt` directly (unescaped, but constrained by construction — base64 alphabet / file-extension characters), and the init IIFE interpolates `initialFlow` directly into `window.__vreaderTargetFlow` — flow strings are constrained upstream by the `sanitizeFlow` allowlist ("paginated"/"scrolled") rather than passed through `escapeForJSString`.
- Most cross-reader notifications carry + filter `fingerprintKey`; the deliberately-global exceptions are the page-turn pair (`.readerNextPage`/`.readerPreviousPage`) and the tap-driven `.readerContentTapped` chrome toggle (step 5 above) — safe because coordinators deinit on unmount.
- Highlight restore refires per `create-overlay` section event (bug #207); `readerAPI.addAnnotation` is idempotent JS-side, so refiring is safe and required for late-loaded sections.
- Empty TOC is NOT posted (sparse books keep the genuine "no contents" state); `parseSelection` rejects collapsed selections and empty/whitespace CFIs.
- `--force-foliate-vertical-rl` launch flag (DEBUG-only, non-writable JS global) exercises the vertical-rl axis path with a horizontal fixture (feature #76 WI-5).

## History

The **live-container regression class**: feature #56 WI-11 swapped the live AZW3 path from the (fully-wired) legacy `FoliateReaderHost` lane to `FoliateBilingualContainerView` → `FoliateSpikeView`, and capabilities wired only in the dead lane were repeatedly lost — bug #260/GH #1130 (no bottom chrome at all), bug #262/GH #1136 (empty Contents sheet, TOC-row/notes navigation, `.readerPositionDidChange` never posted), bug #265/GH #1148 (books always reopened at the start; the controller's header calls it "the third such regression from the wrapper swap"), bug #345 (reading sessions/stats), bug #305/GH #1360 (bilingual state not mirrored on reopen). Other shaping work: bug #189 (Scroll/Paged toggle + layout-ready handshake), #239 (side-tap page turns), #141/#142 (DebugBridge webview registry + reader token), #201/GH #739 (selection → highlight create), #207/GH #765 (highlight restore on reopen), #340 (themed selection), features #57 (TTS extraction), #64 WI-9 (unified highlight popover), #70 WI-4 (calibrated font size), #93 (theme-color parity), #246/GH #1072 hardened dispatch to read `fingerprint.format` rather than the parallel `book.format` string.
