# Module — automation and tooling

## Purpose

The repo's agent operating system: watchdog-wrapped test/verify/audit runners that turn indefinite hangs into bounded runs with one machine-parseable result line, mkdir-atomic locks/leases/ID-reservation for the feature #130 parallel lane harness, a ghost-process sweeper, a prompt-injection scanner with a CI canary, and Claude Code hooks that mechanically enforce the tracker/merge/verification gates. Everything lives in `scripts/` (24 shell scripts + `lib/` + `__tests__/`) and `.claude/hooks/` (6 shell hooks — 5 merge/tracker-blocking enforcement gates plus `refine_prompt.sh`, a non-blocking prompt-refinement hook — + `lib/code-paths.sh`), wired by `.claude/settings.json` and driven autonomously by 4 cron prompts in `.claude/cron-prompts/`.

## Key files and types

Watchdog wrappers (each emits ONE final `RUN-* RESULT:` line; waits on the exact pid per rule 49):
- `scripts/run-tests.sh [suite]` — wraps `xcodebuild test -only-testing:` pinned to a UDID (`TEST_UDID` env, else first booted sim). `TIMEOUT_SECS` default 900. On timeout kills the process tree and `pkill -9 -x SWBBuildService` — but ONLY when no sibling `xcodebuild` is alive (feature #130 WI-3 sibling-safety; `RUN_TESTS_SIBLING_CMD` is the test seam). Emits `RUN-TESTS RESULT: SUCCEEDED|FAILED|TIMEOUT|NO_BOOTED_SIM`; exits 0/1/3/2.
- `scripts/run-android-tests.sh` — the Android analog (feature #107 PR-B). Default command is the Spike-B harness `spikes/android-reader-bench/run-bench.sh` (CHAPTERS=6); `ANDROID_CMD` overrides. Requires an `emulator-NNNN … device` serial for the default command only. `TIMEOUT_SECS` default 1200. Recursive `kill_tree` plus a Gradle-daemon snapshot diff so a timeout kills only daemons THIS run spawned. Emits `RUN-ANDROID-TESTS RESULT: SUCCEEDED|FAILED|TIMEOUT|NO_EMULATOR`.
- `scripts/run-android-verify.sh` — thin `exec` delegate over run-android-tests.sh with verify defaults (CHAPTERS=24, SCROLLS=2, `TIMEOUT_SECS` 1800).
- `scripts/run-codex.sh [-m MODEL] [-e EFFORT] [-o OUTFILE] "<prompt>"` — runs `codex exec --sandbox read-only` with stdin CLOSED (`< /dev/null`, the load-bearing fix for the rule-53 stdin-wedge ghost), `CODEX_TIMEOUT_SECS` default 300, marker `__RUN_CODEX_WATCHDOG_KILLED__` in the output file on timeout, exit 124. Model defaults inherit `~/.codex/config.toml` rather than pinning a stale name.
- `scripts/tdd-guardian-test.sh` — platform-routed TDD Guardian command: `code_paths_platform` over working-tree + staged + untracked changes (with `--no-renames`); `android-spike` → run-android-tests.sh, `android-app` → gradlew via the wrapper or exit 2 refuse-to-green if no app shell, else the iOS `xcodebuild build-for-testing` + `test-without-building` lane.

Lane-harness primitives (feature #130; normative contract is rule 55 / [[Decision — six-gate workflow and lane dispatch]] — this section covers script-level mechanics only):
- `scripts/lib/lock.sh` — THE single mkdir-atomic lock helper: `lock_acquire <dir>` / `lock_release <dir>`. Owner record (`<dir>/owner`: pid=, start=, host=, created=) is published atomically (tmp + mv). Steal ONLY on dead pid or start-time mismatch (PID reuse); a live matching owner is NEVER stolen regardless of age. Steals serialize under a `<dir>.steal.d` mutex that no non-holder ever reaps inline — `sweep-ghosts.sh` is the single reaper. `LOCK_OWNER_PID` overrides the recorded pid.
- `scripts/agent-lock.sh {acquire|release} <name> | status` — named mutexes under `.claude/locks/<name>.lock.d` (`dispatch`, `tracker-write`, `cron-<kind>`). Records the GRANDPARENT pid by default (the long-lived session process, not the per-call zsh). Prints `AGENT-LOCK RESULT: ACQUIRED|BLOCKED|RELEASED|NOT-OWNER`.
- `scripts/sim-lease.sh {acquire {test|verify} | release <udid> | status}` — purpose-tagged exclusive UDID leases (rule 52 mechanized): `test` capacity 2, `verify` capacity 1, a UDID never serves both. Verify resolution ladder: `VERIFY_UDID` env → `.claude/state/verify-udid` → booted iPhone 17 Pro → any iPhone 17 Pro (booted on lease). Capacity check + acquire serialized under `sim-select.lock.d`; `held_count` counts only LIVE leases.
- `scripts/reserve-id.sh {bug|feature}` — atomic next-row-ID: max(tracker max, persisted counter) + 1; counter in `docs/.id-counters/` (local state), lock in `docs/.id-locks/`. Closes the documented cron ID race.
- `scripts/deps-check.sh {bug|feature} <id> | --lint <file>` — typed `Deps:[…]` readiness gate. Edge grammar `bug:#N|feat:#N|gh:#N|design:#N`; bare `#N` inside the brackets is an ERROR. Exit 0 READY / 2 BLOCKED / 1 malformed / 3 row not found / 64 usage. Escaped-pipe-safe cell parsing; rows with fewer than 8 pipe-fields FAIL CLOSED; a `BLOCKED: needs-design (#N)` marker blocks regardless of tokens.
- `scripts/check-write-set.sh <worktree> <prefix>...` — the trust-but-verify gate: `git diff --name-status -M origin/main...HEAD` must stay inside declared prefixes and off the forbidden surfaces (`project.yml`, `docs/bugs.md`, `docs/features.md`, `docs/architecture.md`, `README.md`, `vreader.xcodeproj/`); standing allowance `.claude/codex-audits/`. Fails CLOSED on git errors; optional `CHECK_LANE_PLATFORM` rejects cross-platform diffs via `code_paths_platform`.
- `scripts/worktree-setup.sh <id> <branch>` / `worktree-teardown.sh <id> [--force] [--delete-branch]` — lane worktrees under `.claude/worktrees/<id>`, cap 2, clean-main-tree precondition with a single carve-out for the owner's standing `vreader.xcodeproj/project.pbxproj` signing edit; teardown sweeps the worktree's DerivedData by `WorkspacePath` and deletes the branch only post-merge.
- `scripts/sweep-ghosts.sh [--kill]` — detects/reaps idle (<1% CPU) processes past `THRESHOLD_MIN` (default 120) in the known leak classes: `tail -f`, `log stream`, `codex`, `xcodebuild test|build`, `am instrument`, `adb … logcat`, `http.server`, and `until/while … do sleep N` waiter loops. Never flags SWBBuildService, idb_companion, the Gradle daemon, or a booted emulator. Also the SINGLE reaper for #130 state: stale lock/lease dirs (dead-pid owners only), dead `.steal.d` mutexes, orphaned lane worktrees. Final line `SWEEP-GHOSTS RESULT: CLEAN|FOUND <n>|KILLED <n>`.

Security (rule 54, origin: the real 2026-06-28 issue-comment APK-lure attack on issues #1841/#1847):
- `scripts/scan-untrusted-content.sh [FILE]` — text-only (never fetches URLs) scanner emitting `FLAG <category>: <evidence>` lines; categories `binary-link`, `foreign-release`, `link-deception`, `pipe-to-shell`, `injection-phrase`, `base64-blob`, `url-shortener`. Exit 2 = quarantine. Trusted owner defaults to the git remote owner, fallback `lllyys`.
- `scripts/injection-canary-test.sh` — 10 malicious fixtures (incl. the exact 2026-06-28 shape and a trusted-owner link-deception case) must quarantine with the expected flag; 5 benign fixtures must pass clean.

Verification / gesture / round-trip tooling:
- `scripts/sim-tap.sh {launch|label|xy|swipe|button|tree|shot}` — idb-based CU-free simulator gesture driver (exists because MCP computer-use cannot see the Xcode-nested Simulator.app); `SIM_UDID` override.
- `scripts/run-webdav-roundtrip.sh` (feature #116 WI-6, throwaway `rclone serve webdav` → Android `WebDavRoundTripConnectedTest` at `10.0.2.2:$PORT`), `run-opds-roundtrip.sh` (#117 WI-2), `run-ai-roundtrip.sh` (#118 WI-5, OpenAI-compatible SSE stub) — each owns its server's lifecycle and kills by exact PID (rule 49; the 2026-06-23 subshell-pid http.server leak is the named precedent).
- `scripts/verify-release-no-debugbridge.sh` (feature #44 acceptance: zero DebugBridge surface in Release) and `verify-debug-has-debugbridge.sh` (bug #121 regression: Debug Info.plist carries the `vreader-debug` scheme); `grant-debug-scheme-approval.sh` pre-grants the LaunchServices scheme-approval plist (bug #123). See [[Module — debug bridge]].
- `scripts/b329-1px-sweep.sh` / `b329-analyze.py` / `b329-gesture-probe.sh` — bug #329 EPUB continuous-scroll analysis harness.

## Data flow

Cron loop: 4 session crons (verify `9 * * * *`, bugfix `39 * * * *`, watchdog `54 4 * * *`, feature `24 */2 * * *`, per `.claude/cron-prompts/watchdog.md`) each log `FIRED`/`ENDED <outcome>` to `.claude/cron-logs/`. Each takes its `cron-<kind>` reentry lock first; bugfix (post #130 WI-7 cutover) picks up to 2 independent `bug`-labeled issues and invokes `/dispatch`; the feature cron self-gates on ≥3 `ENDED work_done dispatch-mode` lines in `bugfix.log` before routing WIs through dispatch. The watchdog cron renews the other crons past the 7-day expiry and runs `sweep-ghosts.sh` every fire. Kill switch: `touch .claude/state/dispatch-kill` forces the inline fallback (still under the `dispatch` lock).

Lock order (total, deadlock-free): `dispatch` → sim leases → id-reserve → tracker-write; a tracker-write holder acquires nothing.

## Edge cases and invariants

- Every long-runner has exactly one owner and one completion channel; watchdogs wait on the exact pid and can never be re-armed by a later invocation (rule 49). Timeout sentinels (`$LOG.timedout`, the `FIRED` mktemp file) are set BEFORE the kill so the parent lets cleanup finish.
- Result lines are the contract: `RUN-TESTS RESULT:`, `RUN-ANDROID-TESTS RESULT:`, `RUN-CODEX RESULT:`, `SWEEP-GHOSTS RESULT:`, `AGENT-LOCK RESULT:`, `SIM-LEASE RESULT:`, `CHECK-WRITE-SET RESULT:`, `WORKTREE RESULT:` — never pipe a live run through `tail`/`grep` (rule 52 rule 5).
- Gates fail CLOSED (deps-check malformed rows, check-write-set git errors, the merge hook's unresolvable-PR-from-main path, tdd-guardian's app-less android-app case); convenience paths fail OPEN only where blocking would break the agent on missing tools (jq/python3 absent).
- Tracker parsing everywhere masks backslash-escaped pipes (`\|`) with `\x01` before splitting cells (bug #361 class).
- `pgrep -x`, never `pgrep -f`, for liveness checks (`-f` matches the grep's own command line).
