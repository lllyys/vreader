# Timeline — bug history and recurring classes

## Purpose

Durable record of vreader's bug tracker: total counts by status, the recurring defect classes with exemplar bug numbers, root causes worth remembering, and the workflow that governs the tracker itself. Sources are `docs/bugs.md` (Summary table = single source of truth for status), `archive/bugs-history.md` (2,122 lines of archived causes/solutions/lessons and 148 `### Bug` detail entries), and `docs/tasks.md` (the triage inbox, whose earliest triage records date to 2026-03-08/09). `archive/plans/` (20 files) is also attributed to this dossier but is a known residual: it mixes bug-fix plans with feature plans and spike notes and has not yet been split file-by-file between here and [[Timeline — feature delivery history]]. Two other former `archive/` residents have since moved out: `archive/comprehensive-testing-guide.md` now belongs to [[Module — test architecture]] and `archive/pr-checklist.md` to [[Decision — six-gate workflow and lane dispatch]] — neither is bug-history material.

## Recurring classes (with exemplars)

- **TXT position-persistence saga (#19 → #23 → #24 → #25 → #26 → #27, later #289)** — the tracker's founding epic. Root causes stacked: `DispatchQueue.main.async` restore before layout (#19), missing `scenePhase` wiring + fire-and-forget `Task` in `onBackground()` killed mid-hop (#23/#24), TextKit 1 compatibility-mode relayout resetting `contentOffset` (#25/#26), visible flash-then-jump (#27 — re-fixed 2026-05-31 in v3.41.3 after regressing in the chunked path), and a save that omitted `contentInset.top` so position drifted ~2 lines earlier per session (#289).
- **UITextView highlight crash saga (#47, twelve fix versions v1–v12)** — ended with the archived lesson "ANY text storage modification on a visible UITextView with active selection will crash". Final fix: `HighlightingLayoutManager` (custom `NSLayoutManager` in `vreader/Views/Reader/HighlightableTextView.swift`) draws highlight rects in `drawBackground(forGlyphRange:at:)`, never touching text storage. Companion bugs: #54 (chunked CJK highlights wiped by cell reuse), #55 ("persisting data is only half the story" — no load-on-open path).
- **Chunked-reader parity (#48, #52, #53, #54, #99, #232, #322, the #27 reopen)** — `TXTChunkedReaderBridge` (the >500K-UTF-16 `UITableView` path introduced by #13) repeatedly missed features the plain bridge had. Archived lesson: "Every feature wired to a standard bridge must also be wired to the alternative bridge."
- **`@Observable` didSet/observation recursion (#15/#16/#17, #191, #222, #226)** — reading `viewModel.currentOffsetUTF16` in a SwiftUI body fed back into the bridge (infinite layout, 100% CPU); later, clamping `didSet`s that re-assign the property (`AutoPageTurner.interval` #191, `ReaderSettingsStore.autoPageTurnInterval` #222, `TTSService.rate` #226) re-entered the synthesized setter forever → stack overflow.
- **Gesture-interception overlays (#20, #21, #32, #63, #70, #81, #338)** — WKWebView/UITextView/PDFView internal recognizers eat taps; conversely a SwiftUI `Color.clear.contentShape(Rectangle())` overlay (`TapZoneModifier`) blocked ALL scrolling under it (#70). Lesson: tap detection belongs inside the bridge via `UITapGestureRecognizer` + `shouldRecognizeSimultaneously`.
- **Foliate live-container capability drops (#246, #260, #261, #262, #265, #287, #305, #334, #176, #229)** — feature #56 WI-11 introduced `FoliateBilingualContainerView` as the live AZW3/MOBI route while the `FoliateReaderHost`/`FoliateReaderContainerView` trio stayed as dead code holding the capabilities. Each capability (bottom chrome #260, TOC + locator navigation #262/GH #1136, cross-session position #265, 44pt highlight hit tolerance #287, bilingual state #305, TTS #176) had to be re-wired onto the live path one bug at a time. See [[Module — Foliate AZW3 reader]].
- **Per-format wiring gaps** — a feature lands on 1–4 of the 5 format hosts and silently no-ops elsewhere: haptics only in MD (#172), Auto Page Turn only TXT/MD (#156/#157), EPUB `fontFamily` never injected (#168), Simp/Trad transforms unreachable in native mode (#120, #178), TXT bilingual missing its `handlePositionChange` trigger (#245), session time absent on the live engines (#345). See [[Architecture — reader dispatch and format hosts]].
- **Re-skin/refactor regressions** — feature #60 chrome re-skin broke 9/25 verification XCUITest identifiers (#209, #210); feature #62 WI-5 dropped TOC auto-scroll (#248) and the Notes delete affordance (#249, regressed again as #296); feature #63 broke search UITests + HIG touch targets (#223, #224); feature #54 WI-3 deleted the `TapZoneOverlay` page-turn producer, killing side-tap page turns in all native readers (#239).
- **EPUB continuous-scroll saga (#327, #329 ×4 rounds, #347 ×2, #331, #332, #346, #349, #352)** — the feature #71 stitch + windowed scroll produced compensation-upon-compensation; #329's round-4 archived recommendation: the structural invariant should be "never mutate window/scrollTop during active scroll" (area: `vreader/Views/Reader/EPUBContinuousScrollCoordinator.swift`). #332 pinned a stitch-specific 404: `EPUBChapterBodyRewriter.rewriteAttributes` absolutized `src` but not SVG `xlink:href`.
- **Readium default-flip regressions (#299, #302, #303, #313, #316, #318, #339, #340, #345; the burned #309/GH #1403)** — flipping the default EPUB engine to Readium re-opened chrome, highlight-edit, TOC-focus, and selection-menu gaps the legacy engine had already solved. See [[Module — EPUB reader]].
- **Bilingual translation cache/alignment (#266, #268, #304, #306, #330, #333, #341, #342, #343, #344)** — misaligned paragraph injection (#266), enumerate-vs-`ChapterSegmenter` unit-model divergence (#268), re-translate deleting the cache row before the replacement lands (#341), `providerProfileID` baked into the cache key so re-translate and bilingual never share one canonical translation (#342), and `.timedOut` mislabeled as "offline" (#333, in `ChapterTranslationService.mapTransportError`). See [[Module — bilingual translation]].
- **DebugBridge / verification-harness bugs (~42 DevTools rows)** — #111 (fixtures shipping in Release), #121 (URL scheme never registered), #123 (LaunchServices one-shot "Open in vreader?" approval prompt swallowing `simctl openurl`; fixed by `scripts/grant-debug-scheme-approval.sh`), #259 (incremental build silently dropping the injected scheme — build phase declared no output files), #192 (`verify_*` methods not discovered by XCTest), #242 (XCUITest sandbox blocks `simctl openurl`), #250–#257 (registry races, sheet/detent/eval command gaps), both #237 rows. - **Cross-platform contract bugs (#354, #355, #356)** — all filed 2026-06-17 from one independent Codex review of the Android port: self-contradictory converted-Kindle fingerprint spec, a conformance lane that never byte-diffs Swift-vs-Kotlin output, and missing NFC normalization in canonical identity. See [[Module — cross-platform contracts]].

## Verification-theater lessons

Several reopens trace to weak verification, now encoded as re-close bars: #329 was closed on a 60px synthetic DebugBridge sweep and reopened with a user-mandated **1px-granularity** bar; #283 was flipped VERIFIED without running its binding large-CJK memory gate; #289's tests injected offsets into `updateScrollPosition`, bypassing the buggy `reportScrollPosition` save side; #279 passed proxy (outer-scrollView) verification while the inner DOM scroller stayed unlocked; #347's round-1 close was the "4th exception-close overturned by a device re-report this week". Most fix-iterated / most-reopened bugs, split by the metric each count actually reflects — these are three different measures, not one ranking: by shipped fix-version count before ever landing FIXED — #47 (12 versions, v1–v12), #45 (5 versions), #62 (3 versions, v1–v3); by verification-round count (FIXED → device-reported regression → re-FIXED, per the recurring-classes entry above) — #329 (4 rounds) and #347 (2 rounds); by confirmed reopen-cycle count (an archived FIXED → REOPENED → re-FIXED entry) — #27, #283, #287, #313, #323, #336 (1 reopen apiece, i.e. 2 total close cycles each).

## The bug workflow

- `docs/tasks.md` is the inbox (triage = classification only); `docs/bugs.md` is the tracker; broken-implementation → bug, never-implemented → feature; a re-report of a FIXED bug is a REOPEN, not a duplicate.
- Fix workflow (binding, in `docs/bugs.md` Rules): Understand → RED → GREEN → REFACTOR → Verify → Track; on FIXED, record cause/solution/lessons in `archive/bugs-history.md` and remove the Open-Bug-Detail entry.
- Statuses: TODO, IN PROGRESS, FIXED, PARTIALLY FIXED, REOPENED, DUPLICATE, WONT FIX. IDs come from `scripts/reserve-id.sh bug` (atomic); current dependency edges live in a typed `Deps:[…]` token parsed by `scripts/deps-check.sh` (feature #130 / rule 55).
- Every bug row gets a GitHub issue mirror (`GH: #N` in Notes); PRs use `Refs #N`; the GH issue closes only after device verification (label `awaiting-device-verification`) or a narrow `verification-exception` backed by a high-fidelity integration test plus an evidence file under `dev-docs/verification/`.

## History

Tracker spans 2026-03 (bug #1, "CJK search returns no results") through 2026-07 (bug #361, fixed for feature #130's Gate-5b). Roughly the first 54 bugs were user-reported reader fundamentals (position, highlights, search, chrome); the middle band (#103–#272) is dominated by the DebugBridge/verification harness build-out and per-format parity; the late band (#279–#356) by design-fidelity re-skins, Readium/continuous-scroll/bilingual sagas, and Android-port contract audits.
